「내 여행 스타일 테스트」

사이트에 들어오면 먼저 간단한 여행 성향 테스트를 진행합니다.

예를 들어
“여행에서 가장 중요한 것은 무엇인가?”라는 질문에
맛집, 자연, 사진, 액티비티, 휴식 중 하나를 선택하고,
계획형인지 즉흥형인지와 같은 질문도 포함해서 총 10개의 질문에 답하게 됩니다.

사용자가 모든 질문에 답하면, 선택한 결과를 바탕으로 여행자 유형을 분석합니다.

예를 들어 결과가 **‘감성 탐험가’**로 나온다면,
감성적인 여행을 선호하는 사용자에게 적합한 여행지로
강릉, 전주, 부산 등을 추천합니다.

그리고 이 추천 결과를 단순히 글로 보여주는 것이 아니라,
대한민국 지도에 추천 여행지를 표시해서 사용자가 한눈에 확인할 수 있도록 만듬.



「한국 드라이브 코스 생성기」

먼저 사용자가 출발지와 목적지를 입력합니다.

예를 들어 출발지를 서울, 목적지를 부산으로 설정할 수 있습니다.

그다음 여행 스타일을 선택합니다.

예를 들어
바다, 카페, 맛집, 산, 사진 등의 항목 중에서
자신이 원하는 여행 스타일을 선택할 수 있습니다.

사용자가 선택을 완료하면, 선택한 조건을 바탕으로 지도 위에 나만의 여행 루트가 생성됩니다.
그리고 단순히 출발지와 목적지만 보여주는 것이 아니라,
중간에 원하는 경유지를 추가하거나 여행지를 필터링할 수도 있습니다.

전체 이동 거리와 예상 소요 시간, 예상 여행 비용도 계산할 수 있도록 구성합니다.

추가로 마음에 드는 여행 루트는 저장할 수 있고,
여행지를 직접 고르기 어려운 사용자를 위해 랜덤 여행지 생성 기능도 넣을 수 있습니다.

*홈페이지 주제 구체화

내 여행 스타일 테스트는 범위가 넓어질수록 여행지, 여행 스타일, 질문 항목 등 추가해야 할 기능이 많아져 전체적인 기능이 복잡해질 것 같음. 따라서 처음부터 전국을 대상으로 하기보다는 경기도, 강원도처럼 특정 지역을 정해서 범위를 좁혀 진행하면 개발하기에도 부담이 적고, 완성도 있게 구현할 수 있을 것 같음. 이후 기본적인 기능이 안정적으로 구현되면 다른 지역을 추가하는 방식으로 확장할 수 있을 것 같음.

드라이브 코스 생성기는 자차를 가지고 있는 사람만 이용할 수 있기 때문에 타겟층이 비교적 한정되어 있다는 점이 아쉬움. 자차가 없는 사람이나 대중교통을 이용하는 사람도 사용할 수 있도록 범위를 넓히면 더 많은 사용자가 이용할 수 있을 것 같음. 예를 들어 자동차뿐만 아니라 대중교통, 도보, 자전거 등 다양한 이동 방법을 선택할 수 있도록 한다면 특정 사용자에게만 필요한 서비스가 아니라 다양한 여행객이 사용할 수 있는 서비스가 될 것 같음.

다른 주제와 마찬가지로 특정 조건을 가진 사람만을 대상으로 하기보다는 최대한 다양한 사용자가 이용할 수 있도록 타겟층을 넓히는 방향으로 기획하면 좋을 것 같음. 이를 통해 사용자의 선택지를 늘리고, 실제로 활용할 수 있는 기능도 더 다양하게 구성할 수 있을 것 같음.
